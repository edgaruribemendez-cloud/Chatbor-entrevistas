# Documentación breve del Chatbot para entrevistas


## Librerías a instalar por medio de linea de comando
pip install nltk scikit-learn

## Librerías a instalar en código
Se requiere ejecutar al menos una vez el código con estas instraucciones, se encuentran comentadas en el código fuente
Documentadas en README por seguimiento
EJEMPLO: nltk.download('libreria')
punkt
wordnet
omw-1.4

## Archvios necesarios para ejecución
Archivo Base (Chatbot.py)
Archivo intents.json que funciona como base de conocimiento


## NOTA
El archivo intents.json se debe de encontrar en la misma ruta en la que se encuentra el archivo Chatbot.py
